# Security Playbook — учебный набор по реагированию на инциденты

Личный учебный проект: план реагирования на инциденты (IR-план) и плейбуки для вымышленной компании «Альфа-Трейд» (интернет-магазин, ~300 сотрудников; NGFW, WAF, антивирус, EDR, SIEM, облачная почта).

> Учебный материал. Сроки уведомления регуляторов (152-ФЗ, 187-ФЗ) и другие нормативные детали нужно сверять с актуальными текстами законов.

## Плейбуки

Каждый плейбук переписан по итогам двух рецензий и переработан для удобства чтения. Структура: TL;DR, шпаргалка на первые 30 минут, «Чего делать нельзя», затем 17 разделов (цель, паспорт, подготовка, RACI, триаж с деревом решений и отдельными ветками для L1 и L2, сдерживание, артефакты, расследование, устранение, восстановление, коммуникации с шаблонами, чек-лист закрытия, метрики, типичные ошибки, профилактика, учебная ситуация, источники), раздел «Допущения и ограничения» со всем, что нужно сверить перед реальным применением, и приложения: MITRE ATT&CK, источники данных и триггеры, примеры запросов, сокращения.
